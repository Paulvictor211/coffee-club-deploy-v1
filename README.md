# Coffee Club static deployment

Entry point: `index.html`

Upload the complete contents of this folder to a GitHub repository. It is a static site and does not require a build step, package manager, server runtime, or dependency installation.

Typography is loaded from Google Fonts by `index.html`; an internet connection is required for those fonts. All local image assets used by the page are included in `assets/`.

For GitHub Pages, enable Pages for the repository’s main branch and select the repository root as the publishing folder.
